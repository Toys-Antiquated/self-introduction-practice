# self-introduction-practice

## 概要
COACHTECH 教材 Tutorial 5-1「HTMLの基礎 ハンズオン演習」で作成しました。
初めてのタイトルから、箇条書き、プルダウンリストなどの設定をしてまうｓ。

## 使用技術
- HTML5
- 過去の教材から得たコード言語をNotionにまとめて即時閲覧、記載できるようにした

## 学んだこと
- やはり、自身で手を動かしてみることの大切さ
- 実際にコードに触れて画面の表示結果がどう変わるのかを知る体験の重要性
- なにより、コードを用いて作ることが楽しかったこと

## 動作確認
コードの位置により表示箇所、画面繁栄が変わるので２つのウィンドウでコードを確認し、
画面にどう結果が反映されるのかを適時画面をリフレッシュして確認すること
